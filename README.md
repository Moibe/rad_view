# RAD View

Panel de administración de RAD (API de reconocimiento de documentos): API keys de los clientes y uso.

SvelteKit 2 · Svelte 5 · TypeScript · Tailwind v4 · shadcn-svelte · Drizzle ORM + SQLite · adapter-node.

```bash
npm install
cp .env.example .env
npm run db:migrate
npm run db:seed:admin
npm run dev        # http://localhost:4900
```
